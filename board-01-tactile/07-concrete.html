02Type — engineering labels, not voices

Concrete doesn’t
use italics.

Space Grotesk: geometric, slightly weird, reads like signage cast into a facade — all-caps at heavy weight with −0.02em tracking. IBM Plex Mono does every label, dimension and date. Two families, zero decoration, letterspacing ≥ +0.2em on anything small.

03Recipes — the material in CSS

Cast-slab surface

.slab{
  background:linear-gradient(180deg,#333840,#2D3138);
  border:1px solid rgba(231,229,223,.09);
  border-radius:2px; /* never rounder */
  box-shadow:
    inset 0 1px 0 rgba(255,255,255,.05),   /* top glint */
    0 18px 36px -20px rgba(0,0,0,.7);     /* mass */
}

Poured-noise texture

body::after{
  content:""; position:fixed; inset:0;
  pointer-events:none; opacity:.5;
  mix-blend-mode:overlay;
  /* SVG: feTurbulence fractalNoise,
     baseFrequency .9, numOctaves 2,
     rect opacity .28 — pores, not sand */
  background:url("noise.svg");
}

Engraved lettering

.carve{

   engraved ≠ embossed ≠ neon */

05Steal / skip

Steal this

  • Texture at 15–30% overlay opacity, always mix-blend-mode:overlay — pores, not TV snow.
  • Border-radius ≤ 4px. Corners should look struck from a mold.
  • Hover states by material logic: rows darken, labels shift to orange, nothing “lifts.”
  • Micro-labels in mono with +0.2em tracking: spec-sheet text is free architecture.

Skip this

  • Photos of brick walls as backgrounds — that’s wallpaper, not concrete UI.
  • Texture on top of body text; grain is for surfaces, type stays legible ≥ 4.5:1.
  • Grey-on-grey hero copy at 13px (#5A5E64 on #4A4F55 is an accessibility report waiting to happen).
  • Orange everywhere. One strip per screen. It’s a safety marking.
