03

Recipes — the physics of a calm dark UI

Layered slate surfaces

/* black is flat; slate has depth */
:root{
  --bg:#232B33;      /* L* ≈ 18 */
  --card:#2A343E;    /* +2.5 L* each tier */
  --raise:#33404C;
}
body{ background:--bg;
  /* ambient wash, never a gradient headline */
  background-image:
   radial-gradient(900px 480px at 15% -10%,
     rgba(143,180,217,.07), transparent 60%);
}

Border-first elevation

.card{
  border:1px solid rgba(255,255,255,.07);
  box-shadow:
    inset 0 1px 0 rgba(255,255,255,.04), /* top glint */
    0 20px 40px -30px rgba(0,0,0,.9);   /* soft depth */
}
/* On slate, borders do what shadows do
   on paper. Big blurry shadows = night mode
   trying too hard. */

Muted accent system

/* keep chroma ≈ half of a light-mode brand
   color, then glow instead of shout */
.btn-primary{
  background:rgba(143,180,217,.16);
  color:#8FB4D9;
  border:1px solid rgba(143,180,217,.35);
  box-shadow:0 10px 22px -12px rgba(143,180,217,.4);
}
.btn-primary:hover{
  box-shadow:0 0 0 3px rgba(143,180,217,.12);
}

Text on dark, correctly

:root{
  --txt:#DDE6EE;   /* ≈ 75% brightness.
   #fff on dark halates on OLED */
  --txt-2:#93A3B3;  /* secondary ≥ 4.5:1 */
  --txt-3:#5F7080;  /* decorative labels only */
}
/* test: squint. if a card "vibrates,"
   lower its border white by 2%. */

05

Steal / skip

Steal this

  • L* ladder: step surfaces by ~2.5 lightness each — depth you feel, not see.
  • Color as state, never as decor: steel = action, sage = ok, clay = caution.
  • One top-edge highlight per card (inset 0 1px 0 white/4%) — sells “slab,” not “sticker.”
  • Radii 10–14px; rounder starts to feel toy-like on slate.

Skip this

  • #000 and #fff. Pure black crushes shadows; pure white halates on the eye.
  • Full-saturation neon buttons — slate + fluoro reads as a gaming chair.
  • Big soft drop shadows everywhere: dark UI is built with borders.
  • Gradient text, glass panels, animated aurora — those are other aesthetics; pick one.
