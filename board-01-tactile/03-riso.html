2-color · overprint

Riso / Risograph Style

Grain, ghosting
& glorious misprint.

The web version of a duplicator print: fluorescent spot colors that blend like wet ink (multiply), halftone dots instead of gradients, and color layers that never quite register. Imperfection is the brand.

Best for: indie studioszines & music event sitesbrand merch dropsculture pages

01Palette — spot inks, no CMYK

Recycled stock#F4F1E8
Fluoro pink#FF48B0
Riso blue#0F6FC6
Fluoro yellow#FFE44D
Teal / violet#00A99D
Black ink#1D1C19

THE OVERPRINT RULE: every colored layer gets mix-blend-mode:multiply. Pink × blue = purple, blue × yellow = green. That second-pass color is the entire aesthetic — no extra ink, only overlaps.

03Recipes — fake the press in CSS

Misregistered layer

.mis{position:relative; color:#1D1C19}
.mis::before{
  content:attr(data-text);
  position:absolute; inset:0;
  color:#FF48B0;
  transform:translate(4px,-3px);
  mix-blend-mode:multiply;
  z-index:-1;
}

Halftone field

.halftone{
  background:
    radial-gradient(#FF48B0 1.2px,
      transparent 1.6px) 0 0/5px 5px;
  opacity:.85; transform:rotate(8deg);
}
/* rotate the dot grid slightly —
   rosettes appear, like on press */

Duotone photos

img.riso{
  filter:grayscale(1) contrast(1.15)
         brightness(1.05);
  mix-blend-mode:multiply;
}
.riso-wrap{position:relative; isolation:isolate}
.riso-wrap::after{ /* tint pass */
  content:""; position:absolute; inset:0;
  background:#0F6FC6; mix-blend-mode:multiply;
  opacity:.65;
}

Press grain overlay

body::after{
  content:""; position:fixed; inset:0;
  pointer-events:none;
  mix-blend-mode:multiply; opacity:.16;
  background:url("noise.svg"); /* SVG
    feTurbulence, fractalNoise, bf .9 */
}

05Steal / skip

Steal this

  • Two inks and a paper tone. Three max. The limit is the look.
  • Offset every decorative layer by 2–6px; align your text layers to nothing.
  • Halftone instead of gradients for skies, fades and image tone.
  • Let grain live on ::after overlays, never inside the text layer.

Skip this

  • Full-color photography — that’s a magazine, not a riso.
  • Body copy in multiply pink at 12px. Accessibility still exists in 1994.
  • Perfect registration everywhere: one element must be aligned to prove the rest are not.
  • Neon without grain → you’ve accidentally built a Y2K page.
