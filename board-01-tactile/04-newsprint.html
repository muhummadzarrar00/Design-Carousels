The Newsprint™ UI

Cream paper, dot-screen photography, rules everywhere — the interface as Sunday paper.

The Idea

Density is the design

Overview · Aesthetic

Newsprint sells “publication,” not “app.”

By the Desk · 4 min read

Where editorial-web borrows magazine glamour, newsprint goes working press: an off-white stock, coarse halftone dots for imagery, hairline rules boxing every section, and copy packed close like it was sold by inch.

The UI elements stay print-native: square buttons with 2px offset shadows, dotted underlines, marginalia labels in mono. The screen is treated as a broadsheet that happens to be clickable.

Best for newsletters, reading products, journalism, indie press, “everything is a newspaper” brand personas (Stripe’s press pages, Substack-era blogs, Aesop-style restraint with dots).

How it works

Three levers, all CSS

First: paper — never #fff; a warm grey-cream at ~93% brightness with a micro dot texture. Second: rules — the layout skeleton is 1px lines, not cards or shadows. Third: halftone — photos become dot-screens, so every image shares the ink budget.

Get those three right and even a pricing table looks like a classifieds column, which is the whole point.

Typography does the rest: a Didone/Bodoni masthead, an old-style serif for body (Lora, Source Serif), and a mono for kickers, prices and datelines — the “typeset last” voice.

Recipes

Build the press

Halftone images

.imgbox{
  background:
    radial-gradient(#1C1B18 1.3px,
      transparent 1.9px) 0 0/4px 4px,
    linear-gradient(180deg,#E6E1D2,#D8D2C0);
  border:1px solid #1C1B18;
  filter:contrast(.8);
}

Newspaper rules

.hr-section{
  border-top:2px solid #1C1B18;
  margin:0; position:relative;
}
.hr-section::after{content:"";
  position:absolute; left:0; right:0; top:2px;
  border-top:1px solid rgba(28,27,24,.35);
}
/* 2px + 1px = print double rule */

Typeset buttons

button{
  border:1px solid #1C1B18;
  background:#1C1B18; color:#EFEBE0;
  font:500 11px/1 "IBM Plex Mono";
  letter-spacing:.18em; text-transform:uppercase;
  padding:12px 16px;
  box-shadow:3px 3px 0 #7A1F14;
}
button:active{
  transform:translate(2px,2px);
  box-shadow:1px 1px 0 #7A1F14;
}

Aged stock background

body{
  background:#EFEBE0;
  background-image:
    radial-gradient(rgba(28,27,24,.05) 1px,
      transparent 1.4px),
    radial-gradient(rgba(28,27,24,.04) 1px,
      transparent 1.4px);
  background-size:7px 7px, 11px 11px;
  background-position:0 0, 3px 5px;
}

Verdict

Steal / skip

Steal this

  • Dotted underlines and hairline borders as interaction states — cheap, printy.
  • Section labels set in mono caps — the “last typeset” voice of the page.
  • Halftone all images, including avatars — one technique, whole system.
  • 2px + 1px double rules under mastheads and footers.

Skip this

  • Pure white anywhere — #fff shatters the paper illusion.
  • 3+ columns under 1000px: newsprint density needs measure, not micro-columns.
  • Skeuomorphic coffee stains — texture is the style, props are the costume.
  • Small serif under 12px on LCD — print sizes don’t port to screens.
