Recipes — how to actually build it

Cardstock elevation

.card{
  background:#fff;
  border:1px solid rgba(34,31,26,.06);
  border-radius:22px;
  box-shadow:
    0 1px 2px  rgba(34,31,26,.05),  /* paper touch */
    0 10px 24px -8px rgba(34,31,26,.16); /* lift */
}
/* hover = pick sheet up */
.card:hover{
  transform:translateY(-6px);
  box-shadow:0 2px 3px rgba(34,31,26,.05),
    0 22px 38px -12px rgba(34,31,26,.22);
}

Stacked-sheet offset

.pcard{position:relative}
/* the sheet "underneath" */
.pcard::before{
  content:""; position:absolute; z-index:-1;
  inset:10px -6px -8px 10px;
  border-radius:22px;
  background:var(--butter);
  transform:rotate(1.6deg);
}
/* one light source: every fake
   sheet tilts the same way */

Die-cut blob

.blob{
  border-radius:58% 42% 61% 39%
             / 48% 55% 45% 52%;
  box-shadow:inset 0 -6px 0 rgba(34,31,26,.08);
}
/* animate radius slowly and it
   reads as hand-cut paper,
   not a CSS trick */

Steal this / skip this

Steal this

  • One light source — all shadows fall the same direction, same softness.
  • Pastel fills + exactly one graphite ink for every word.
  • Cards lift on hover; buttons press down. Physics sells the material.
  • Let a rotated “sheet behind the sheet” do the layering — zero images.

Skip this

  • Multi-color or blurred-everywhere shadows — instantly fake.
  • Glossy 3D puffs (that’s claymorphism, not papercraft).
  • Texture noise above ~6% opacity; you want tooth, not TV static.
  • Stacking more than 3 sheets — pages read as cluttered, not crafted.
