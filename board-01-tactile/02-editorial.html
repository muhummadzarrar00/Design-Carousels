Style Dossier

Editorial & Print‑inspired Web

The web page as a magazine spread: serif authority, a real column grid, hairline rules doing the layout work, and one spot color of ink.

Set in Playfair Display · Source Serif 4 · Archivo — Filed under: typography-first

§1

The idea, in three columns

Editorial web design borrows three centuries of print grammar and applies it to a browser. Headlines carry real typographic weight. The page is divided by rules, not cards. Density is a feature — a broadsheet earns long attention spans.

The move that sells it is the grid: fixed columns with hairline rules between them, text justified or left-aligned with intent, and small-caps kickers that act as wayfinding. Every element should look placed by an art director, not defaulted by a framework.

Use one ink color for type and one spot color — usually a red — for accents, underlines and section marks. More color and you’re back on the web; less and nobody notices the craft.

Best for: journalism and longform blogs, culture & fashion studios, restaurant and wine brands, any site that wants to feel published rather than posted.

It also ages well: print grammar has no “2019 glass panel” problem. Serif + grid + rules will still feel deliberate in a decade.

Reference moods: Sunday broadsheets, old Knopf book jackets, The Gentlewoman, Monocle spreads, The New York Times Upshot.

Recipes — CSS with a printing press in mind

Column grid + rules

.spread{
  columns:3;
  column-gap:36px;
  column-rule:1px solid rgba(22,20,18,.22);
}
.spread p{
  text-align:justify;
  hyphens:auto;   /* kills rivers */
}

Drop cap, red ink

.lede::first-letter{
  font:900 4.6em/.78 "Playfair Display";
  float:left;
  padding:.06em .1em 0 0;
  color:#C8321E;
}

Brass rule (double)

.rule-double{
  border-top:4px double #161412;
  border-bottom:1px solid #161412;
  padding:6px 0;
}
/* thin above, thick below —
   or flip it, but be consistent
   page-wide. Always. */

Pull quote w/ hang

blockquote{
  font:italic 500 clamp(26px,3.4vw,40px)
       /1.28 "Playfair Display";
  border-block:1px solid #161412;

}

  text-indent:-.35em; /* optical hang */

§6

Steal this / Skip this

Steal this

  • A real grid: 12 columns, visible hairlines only where they organize content.
  • Optical alignment — pull quote marks and rules 2–3px outside the column.
  • Section numbers (¶, §, folios) as free “design detail” that reads as print DNA.
  • Italic decks under roman heads: instant hierarchy with one family.

Skip this

  • Grey body text — press ink on newsprint, or it’s not print.
  • Justified columns without hyphens:auto: rivers everywhere.
  • Everything centered. Newspapers left-align with ragged-right columns.
  • Second and third accent colors. The spot is one color. That’s the joke.
